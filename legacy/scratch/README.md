# Archived WST scratch work

Moved from the repository-root `scratch/` folder on 2026-09-22. Both original files
were preserved byte for byte.

| File | Purpose |
|---|---|
| `wst_dev.py` | Interactive IPython/VS Code cells used during early WST exploration. |
| `windows.npz` | Original local window cache used by those cells; gitignored. |

The script retains its historical `scratch/windows.npz` paths, IPython magics, and
exploratory calls. It is an archival snapshot, not a supported command-line entry
point. No active package, script, test, or current notebook depends on this folder.
Its data/grouping assumptions predate the corrected patient-based evaluation.

Use the current extraction/evaluation scripts and the
[corrected comparison](../../architects/patient_vmd_wst_vqc.md) for new work.
A fresh Git clone will not include the local window cache.

Original paths, sizes, and SHA-256 hashes are recorded in the
[cleanup manifest](../../architects/repository_cleanup_2026-09-22.json).
